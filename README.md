# Banco de Dados 
Atividade Banco de Dados 
Essa atividade irá descrever o minimundo que foi definido como um Sistema de controle de estoque e registro de manutenções. 
A finalidade do sistema é ajudar empresas que tenham de média a grandes demandas para que se possa ter um melhor controle e gestão. Lembrando que ele não trabalhará com moeda, apenas com registros de entradas e saídas. Servirá apenas para registro.

IDE utilizada para o desenvolvimento do Banco de Dados. SQLite.
